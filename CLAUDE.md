# Repository skills

In addition to the freqtrade codebase, this repo carries agent skills under `.agents/skills/` (installed via `npx skills add ...`). Load these when a request matches their trigger phrases.

## creattopia-production

Plans and scripts high-retention short/mid-form video content: Surreal E-Commerce (CGI/impossible-physics product ads) and faceless documentary/story channels. Covers brand identity (Vision Board, Ikigai, Icon Factors), concept validation (Triple AAA, VVA, Dream Avatar), cinematography, editing pacing, platform export settings, channel growth/scripting formulas, and a full director-prompt spec for generating one consistent, deliberately crude MS-Paint-style image per script timestamp.

See `.agents/skills/creattopia-production/SKILL.md`. Does not generate media itself — it produces the plan/script/style-brief that a generation tool (e.g. `higgsfield-generate`) then executes.

## higgsfield-* skills

Media generation via Higgsfield AI: `higgsfield-generate` (images/video/3D/audio), `higgsfield-product-photoshoot`, `higgsfield-marketplace-cards`, `higgsfield-soul-id` (character/face consistency), `higgsfield-websites`. See each skill's `SKILL.md` under `.agents/skills/`.
