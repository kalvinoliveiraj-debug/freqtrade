# Creattopia Production Framework

Turns a raw content idea into a structured production plan: brand identity → script → shot list → edit pacing → export settings. Two supported visual paradigms:

1. **Surreal E-Commerce** — physical products performing impossible, physics-defying feats (CGI/AI-augmented). See `references/surreal-ecommerce.md`.
2. **Faceless channels** — asset-driven documentary/story/essay channels with no on-camera presenter. See `references/faceless-channels.md`.

This skill does not generate media — it produces the plan (scripts, shot lists, pacing notes, export specs) a human or a generation tool then executes.

## Workflow

1. **Clarify the goal.** Is this (a) a single video/ad concept, (b) a channel identity/brand build, or (c) a content series / scripting-system choice? Ask only what's missing — don't front-load all frameworks at once.
2. **Brand identity (new channel only).** Run the Vision Board + Ikigai exercise, then extract Icon Factors. See `references/vision-ikigai-icon.md`. Skip this for one-off video requests on an already-established channel.
3. **Validate the concept.** Check the idea against the Triple AAA framework, and pressure-test drafts with VVA. For personal/story-driven content, build the specific Dream Avatar first — don't write for a generic audience. See `references/aaa-vva-dream-avatar.md`.
4. **Pick a scripting formula.** Match production budget/time to one of the four scripting formulas (Tryhard / Efficient / Dot-Point / Brazy). See `references/growth-scripting.md`.
5. **Write the script** using the abbreviation shorthand (`th`, `cs`, `vo`, `pp`, `hv`, `vo/sd`) so shot type and post-production intent are unambiguous. See `references/production-blueprint.md`. If the deliverable is a full wobbly-MS-Paint image sequence (one image per script timestamp), hand the script to the director spec in `references/wobbly-image-sequence-prompt.md` instead of improvising per-image prompts.
6. **Shot/cinematography plan.** Apply grid alignment, camera angle psychology, and lighting setup. See `references/cinematography-lighting.md`.
7. **Edit pacing plan.** Multi-layer timeline, visual-asset refresh cadence, J-cuts, pattern breaks. For montage/progress content, consider the compound time-lapse technique. See `references/editing-post-production.md`.
8. **Export spec.** Match resolution/codec/bitrate/upload protocol to the target platform(s). See `references/export-protocols.md`.
9. **Series/growth framing (recurring channel work only).** Group into a 5–7 episode series with a completed series questionnaire, and place the channel on the Hormozy More → Better → New scaling ladder. See `references/growth-scripting.md`.
